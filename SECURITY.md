# Security policy

## Reporting a vulnerability

Please email **info@steppingedge.com** with:

- the repository or product affected
- steps to reproduce
- the impact you expect

Don't open a public issue for security problems. We aim to reply within 3 working days.

## For our team

If you find a leaked secret, rotate it first, then tell your project lead. Removing it from Git history is not enough on its own.
