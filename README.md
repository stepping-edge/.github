# .github

Org-wide defaults for Stepping Edge. GitHub applies the files here to every repo in the `stepping-edge` org that doesn't have its own copy.

| File | What it does |
| --- | --- |
| `profile/README.md` | The public org profile page |
| `pull_request_template.md` | Pre-fills every new pull request |
| `ISSUE_TEMPLATE/` | Bug report and feature request forms |
| `CONTRIBUTING.md` | Branching, commit and review rules |
| `SECURITY.md` | How to report a vulnerability |
| `CODE_OF_CONDUCT.md` | How we treat each other |

**This repo is public.** Never put client names, credentials or internal details here.
